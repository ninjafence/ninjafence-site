NinjaFence Motion G1 UI Guide

NinjaFence-Motion-G1 provides a 4.3-inch touchscreen for everyday positioning and a built-in web interface for machine configuration, calibration, testing, and firmware updates.

4.3-inch touchscreen

Use the touchscreen to enter a target fence position and make fine adjustments. The controller supports Jog+ and Jog− movement in 0.1 mm increments.

Connect to the web interface

  1. Power on NinjaFence.
  2. On a phone, tablet, or computer, connect to the Wi-Fi network NinjaFence.
  3. Enter the default Wi-Fi password ninjafence.
  4. Open a browser and visit 192.168.0.1 or ninjafence.local.
The addresses above are available only while your device is connected to the NinjaFence Wi-Fi network. If one address does not resolve, try the other.

Web interface sections

NinjaFence Configuration

Configure the stepper pulse value, movement speed, and acceleration. Stepper Pulse depends on the machine's motor driver and mechanical transmission. Use NinjaFence Calibration to calculate it from a measured movement.

NinjaFence Calibration

Run a controlled movement, enter the distance the fence actually traveled, and calculate a corrected Stepper Pulse value. Follow the complete calibration procedure before changing this setting.

NinjaFence Default Configuration

Restores the G1 defaults: 256 pulses/mm, 6400 driver steps/revolution, and a 1500 mm maximum software movement limit.

NinjaFence OTA

Use this section to update the NinjaFence firmware over the air. Keep the controller powered throughout the update and do not command movement until the update and restart have completed.

NinjaFence Test

Use the test controls during setup and troubleshooting. Keep the saw blade removed or fully lowered and make sure the complete fence path is clear before running any movement test.

LED status indicator

Solid greenNinjaFence is moving.
Blinking yellowNinjaFence is idle.
Blinking redAn error occurred. Use Unlock to clear the error after correcting its cause.
